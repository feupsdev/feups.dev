## Sobre

A **feups.dev** é um estúdio independente de desenvolvimento web focado na criação de sites com identidade visual própria, interfaces modernas e experiências digitais pensadas para cada negócio.

Cada projeto é desenvolvido com atenção aos detalhes, combinando design, tecnologia e funcionalidade para entregar uma presença digital profissional.

Nosso objetivo é transformar ideias em experiências digitais que transmitam personalidade, confiança e qualidade.

## Desenvolvimento

O portfólio utiliza uma arquitetura baseada em componentes React, com animações desenvolvidas em CSS e IntersectionObserver.

A experiência inclui:

- Interface responsiva
- Animações de entrada e scroll
- Efeitos de parallax
- Indicador de progresso de scroll
- Prévia dos projetos publicados em iframe
- Visualização dos projetos em desktop e celular
- Fallback para sites que não permitem incorporação
- Suporte à preferência `prefers-reduced-motion`
